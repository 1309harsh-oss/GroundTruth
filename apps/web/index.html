AI EVIDENCE ANALYSIS

How GroundTruth audits site evidence.

Every submission triggers an asynchronous analysis pipeline that calculates objective quality metrics, compares perceptual hashes, and runs OCR text recognition without modifying the original evidence.

01

Calculates sharpness to ensure field photos have sufficient visual clarity for audit scrutiny.
02
Perceptual Image Hash (pHash & dHash)
Flags identical or cropped resubmissions across historical milestones via Hamming distances.
03

Extracts on-site signage, chainage kilometer markers, and package identifiers automatically.
