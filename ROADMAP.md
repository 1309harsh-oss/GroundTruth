# Product and Engineering Roadmap

## Phase 0 — Foundation
- Confirm pilot asset category and defect taxonomy.
- Confirm organization roles and approval policy.
- Finalize retention, privacy and evidence access policy.
- Set up repository, environments, CI and database migrations.
- Implement authentication and RBAC.

**Exit:** secure application skeleton with project and user management.

## Phase 1 — Evidence vertical slice
- Projects, sites, milestones and evidence requirements.
- Capture/upload.
- File validation and immutable original storage.
- SHA-256 generation and verification.
- Metadata provenance.
- Evidence detail and history.

**Exit:** end-to-end evidence submission and integrity check.

## Phase 2 — Human review workflow
- Reviewer assignment and queue.
- Review detail page.
- Approve/reject/request correction.
- Corrective action and linked resubmission.
- Append-only audit events.
- Notifications.

**Exit:** usable workflow without AI dependency.

## Phase 3 — Baseline AI screening
- Image quality.
- OCR.
- Exact duplicate and perceptual similarity.
- One pilot defect model.
- Findings and annotations.
- AI routing recommendations.

**Exit:** AI findings available to reviewer with evaluation results.

## Phase 4 — Project knowledge and GIS
- Project geofences.
- Map and spatial filters.
- Specification ingestion.
- RAG retrieval with citations.
- Requirement checklist matching.

**Exit:** grounded milestone context in review workflow.

## Phase 5 — Pilot hardening
- Security review.
- Field testing across devices and conditions.
- AI threshold calibration.
- Performance and recovery tests.
- User training and operational documentation.

**Exit:** pilot-ready release with known limitations.

## Later opportunities
- Additional infrastructure categories.
- Multi-angle capture guidance.
- Advanced segmentation and calibrated measurement.
- Offline capture/sync.
- Cross-project analytics.
- Government/project-system integrations.
- Predictive risk indicators.

## Prioritization rule

Build the smallest complete workflow that creates trustworthy evidence records. Do not prioritize advanced model complexity ahead of evidence integrity, reviewer usability and auditability.
